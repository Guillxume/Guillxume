## 🧑‍💻 About me

I'm a **front-end developer** based in northern France, working on e-commerce at **Neginvest**.

- 🛒 I look after a **fleet of PrestaShop stores** (including multisite setups), from **1.6 all the way to 8.x**
- 🚀 I'm part of our move to a modern stack built on **Next.js** and **Medusa.js**
- 🧩 I build PrestaShop modules with **Symfony**, and interfaces with **React / Next.js**
- ♿ I care about **web accessibility** (RGAA / WCAG compliance work)
- 🤖 These days I'm deep into **AI engineering**: agentic workflows, automation and AI-assisted development
- 🎲 Off the clock, I build tools for my **tabletop RPG** campaigns
